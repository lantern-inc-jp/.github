## 🔦 About Us

**株式会社LANTERN** は、北海道札幌市を拠点とする、
ブランディング・マーケティング・AI活用を軸とした **次世代型ビジネスデザインファーム** です。

戦略を描くところから、手を動かして実装するところまで。
ひとつのチームで、事業の「次の一歩」に伴走しています。

## 🙌 Join Us

LANTERN では、**実践型・長期の学生インターン** を通年で募集しています。

見学や勉強のためのインターンではありません。
実際のクライアント案件に、責任を持つ一人のメンバーとして入ってもらいます。

- 💰 **時給 2,000円** ＋ 業績連動の決算賞与あり
- 🧭 ブランディング / マーケティング / AI活用 のいずれかを軸に実案件を担当
